# 器械购买报表（模板）

> **模板**：复制成 `../XX_器械购买报表_第N期.md` 使用，本文件保持空白。
> 流程定位：**先报表、后讨论、再购买、最后记账**——四个环节一份都不能少。
> 编号规则见下方「报表编号」。

---

## 填表说明（30 秒看完）

1. **谁发起谁填**「拟购」行；全队讨论后把结论填进紧随其后的「实际购买」行（**格式与拟购行完全一样**）
2. **需求参数要写到"能直接照着下单"的程度**——写"买几个电机"不合格，写"直流减速电机 ×4，6–7.4 V，堵转 ≤2 A"合格
3. **拟定型号 = 电商俗名 + 正式名字**，两样都写（俗名用来搜，正式名用来核对）
4. **没讨论完不许下单**；讨论结论记进「讨论记录」区，谁提的意见照原文记
5. 买完之后，金额、店铺、截图**不回填本表**——进《购买记录》（不进仓库那份，见模板 T06）
