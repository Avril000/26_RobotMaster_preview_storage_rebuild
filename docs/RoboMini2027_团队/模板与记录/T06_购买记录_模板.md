# 购买记录（模板）

> **模板**：本文件是空白模板（可进仓库）。
> **⚠️ 真正填了数据的《购买记录》绝对不进这个文件夹**——它的家在
> `RoboMini2027_账目/`（工作空间下的第三个目录，**永不进仓库、永不上传任何网络**）。
> 为什么：里面有真实金额、购买人、店铺和订单截图，属于队内财务隐私。

---

## 使用规则（先读这五条）

1. **每买一笔，记一行**——当场记，别攒着补（订单截图当时就能截，隔几天订单页可能翻不到）
2. **购买快照**：电商订单详情页截图，存 `账目/快照/` 子文件夹，文件名 `CG-xxxx-物品-日期.png`，表格里写文件名引用，**不贴图进表**（md 里嵌图会体积爆炸）
3. **「是否用于本次比赛整机」必须当场勾**——这是赛后分摊的依据，事后回忆必出错
4. **交付方式**：每次线下会议，交付电子件或打印件给白星（记录保管人）
5. **本记录与仓库的唯一接口**：仓库里的《器械购买报表》只留"实际购买"行的型号与成交价；**金额汇总、购买人、店铺、截图只存在本记录**
